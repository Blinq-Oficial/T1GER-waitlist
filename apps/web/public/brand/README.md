# Google sign-in assets

The G icon is the official asset from https://developers.google.com/static/identity/images/g-logo.png. Button styling follows https://developers.google.com/identity/branding-guidelines (reviewed October 4, 2026).

Google Sans Medium 500 uses the Latin WOFF2 subset provided by Google's Fonts API. Its license is included in `Google-Sans-OFL.txt`, from the official `google/fonts` repository, `ofl/googlesans/OFL.txt`. These assets are hosted locally so the sign-in button does not request third-party fonts or images.
